## Overview

A functional e-commerce mobile app built with React Native and Expo. The app fetches product data from an external API, allowing users to browse products, view detailed information, and search by name. It also includes a favorites feature (non-persistent) for a better user experience. The focus was on clean architecture, reusable components, and smooth mobile interaction.

## Key features

- Fetch products from an external API
- Product details page with complete information
- Search functionality for products
- Responsive mobile-friendly design
- Reusable UI components with custom styling
