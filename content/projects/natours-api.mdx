## Overview

Developed a robust backend API for an E-Commerce platform including user authentication, product management, orders, payments, and email notifications. Implemented file upload with Multer, cloud image storage with Cloudinary, Stripe payments with dedicated endpoints and webhooks, nested routes for reviews, and secure email handling with Nodemailer. The API is production-ready and fully documented with a Postman collection for testing.

## Key features

- User Authentication & Role-Based Authorization (Admin/User)
- Product CRUD operations with image upload (Multer) and Cloudinary integration
- Order creation and management
- Stripe Checkout integration with dedicated Payment Endpoint
- Secure Stripe Webhook to confirm successful payments
- Nested Routes for product reviews
- Transactional emails with Nodemailer (welcome, password reset, payment confirmation)
- Global Error Handling & Async Middleware
- MVC architecture with reusable factory controllers
