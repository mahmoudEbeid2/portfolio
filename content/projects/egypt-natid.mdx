## Overview

egypt-natid is a comprehensive data-processing framework built specifically for the Egyptian National ID. Far beyond simple regex, it implements deep mathematical validations, including the Modulo 11 Checksum Algorithm and date-of-birth existence verification. It is designed for high-performance fintech, e-commerce, and healthcare applications, capable of processing 100,000+ IDs in milliseconds. The library includes advanced recursive filtering, bulk statistical analysis, and a global CLI interface.

## Key features

- Strict Structural Validation with Modulo 11 Checksum Algorithm
- Deep Mathematical Verification: Prevents fake IDs and invalid birth dates
- Advanced Demographic Extraction: Birth date, age, gender, and governorate
- Recursive Filtering Engine: Sift through massive datasets by age, region, or gender
- Bulk Statistical Analysis: Instant demographic reports from ID arrays
- 100% Type-Safe: Built with strict TypeScript for excellent Developer Experience (DX)
- Test Utility: Programmatically generate mathematically valid dummy IDs
- Global CLI: Validate and analyze IDs directly from the terminal
- Framework Ready: Compatible with Zod, Yup, and React Hook Form schemas
