## Overview

PayNest is a robust financial engine built with NestJS and Prisma. It handles secure money movement between wallets using ACID-compliant database transactions. The system includes a sophisticated AML (Anti-Money Laundering) layer that flags high-value transfers for admin approval. It utilizes Redis for distributed locking to prevent race conditions and BullMQ for asynchronous background tasks like email receipt generation. Real-time notifications via Socket.io ensure users are instantly alerted of incoming payments.

## Key features

- ACID-Compliant Wallet Transfers with Prisma Transactions
- AML/KYC Fraud Detection: Automatic flagging of high-value transfers (>$10,000)
- Admin Approval Workflow for pending-suspicious transactions
- Distributed Locking via Redis to prevent double-spending in high-concurrency
- Real-time Payment Notifications with Socket.io
- Background Job Processing for Email Receipts with BullMQ
- Dynamic PDF Transaction Statement Generation
- Redis Caching for Wallet Balances with smart invalidation
- Full JWT Authentication & Role-Based Access Control (RBAC)
