## Overview

GeoTrack is a full-stack real-time geolocation project. Users can submit their GPS locations through the React Native mobile app, which updates all connected clients instantly via Socket.IO. The dashboard visualizes all locations on Google Maps with live updates, filtering, and interactive markers.

## Key features

- Backend API: Submit new locations with latitude and longitude
- View all collected locations
- Real-time updates via Socket.IO
- RESTful API endpoints with validation and error handling
- Mobile App: Capture GPS location and send to backend (React Native, Expo)
- Disable send button while fetching/sending location
- Dashboard: Live map display of all locations on Google Maps
- Filter locations by date
- Polyline connection between multiple locations
- Custom markers and labels
- Responsive and interactive dashboard
