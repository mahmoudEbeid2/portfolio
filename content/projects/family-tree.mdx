## Overview

I developed an interactive Family Tree web application with advanced visualization features and secure access. It supports multiple viewing modes, zoom, and detailed individual profiles. I also implemented a custom fallback to resolve an SVG rendering issue on iOS Safari, ensuring full cross‑browser compatibility.

## Key features

- Interactive family tree visualization with multiple viewing modes
- Zoom in/out functionality for easier navigation
- Detailed profile view for each person
- Password-protected access for data security
- Fixed critical iOS Safari SVG rendering issue with a custom fallback
- Achieved full cross-browser compatibility
