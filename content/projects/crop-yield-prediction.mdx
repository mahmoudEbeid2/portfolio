## Overview

A professional project aimed at predicting agricultural crop yields using Artificial Intelligence with a fully interactive user interface. The system combines machine learning with a responsive dashboard to provide accurate predictions and a smooth user experience.

## Key features

- Decision Tree model estimates crop yield from environmental data
- Front-end built with HTML, CSS, and JavaScript in two days
- Firebase integration for storage, authentication, and authorization
- Interactive dashboard for results visualization
- Planned: plant disease detection and weather-based recommendations
