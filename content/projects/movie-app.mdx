## Overview

Developed a comprehensive mobile movie application using React Native and Flutter that displays movies from an external API. Users can browse movies, view detailed information, add favorites to AsyncStorage, and search through the movie catalog. The app provides a smooth user experience with native performance and offline favorites storage.

## Key features

- Cross-platform mobile app (React Native )
- Movie browsing with external API integration
- Detailed movie information display
- Favorites system with AsyncStorage persistence
- Advanced search and filtering capabilities
- Responsive and intuitive mobile UI
- Offline favorites access
- Smooth navigation between screens
