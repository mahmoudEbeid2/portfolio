## Overview

A fully dynamic web application for managing daily tasks, developed entirely with TypeScript without using any static HTML. All interface elements are generated via DOM manipulation, providing a great opportunity to practice clean coding and robust data handling.

## Key features

- Add, edit, and delete tasks
- Search functionality within tasks
- Data persistence using LocalStorage
- Fully dynamic interface powered by JavaScript & TypeScript
