## Overview

I converted a complete Figma design into a fully functional, interactive, and professional landing page using HTML, CSS, and Bootstrap. Focused on pixel-perfect accuracy, responsiveness, clean structure, and consistency with the original design. Added smooth animations, clear hierarchy, and simple JS interactivity with basic SEO best practices.

## Key features

- Precise Figma-to-code conversion without losing design details
- Fully responsive across mobile, tablet, and desktop
- Bootstrap-based layout with customized colors and styling
- Clean, maintainable, and scalable codebase
- Enhanced UX with animations and intuitive navigation
- JavaScript interactivity (smooth scrolling, section navigation, messages)
- Basic SEO (semantic HTML, headings, meta)
