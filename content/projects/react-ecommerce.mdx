## Overview

I developed a modern E‑Commerce web application using React on the front-end and Redux Toolkit for scalable state management. The app integrates with an external API via Axios to fetch and display products dynamically, while maintaining a clean, responsive UI across devices.

## Key features

- Authentication: Login and Sign Up
- Product listing with modern UI
- Product details page
- Favorites system
- Fully responsive design
- Clean, maintainable codebase
- (Planned) Shopping cart functionality
