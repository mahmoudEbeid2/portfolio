## Overview

I developed a modern e-commerce platform specialized in selling electronics, featuring a professional design and smooth user experience. The website integrates dynamic features that simulate real online stores, such as dark/light mode switch, dynamic product display via external API, fully responsive design, real-time product search, advanced shopping cart (add/remove/update with totals), user authentication with validation, and a clean, scalable codebase.

## Key features

- Dark/Light mode switch
- Dynamic product display via external API
- Fully responsive design across all devices
- Real-time product search system
- Advanced shopping cart (add/remove/update quantities with total calculation)
- User authentication (login & signup) with input validation
- Clean, scalable, and maintainable codebase
