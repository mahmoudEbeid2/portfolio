## Overview

Developed a comprehensive SaaS multi-tenant e-commerce platform that allows small business owners to create independent online stores with unique links and dedicated management dashboards. Each seller has a separate storefront and control panel while the system operates on a shared scalable backend. The platform includes a React Native mobile app for store creation in under 5 minutes. Configured a custom mail server (Namecheap) to handle transactional and marketing emails with dedicated addresses for different purposes.

## Key features

- Multi-Tenant Architecture: Each seller gets unique subdomain (e.g., mystore.dokaney.store)
- Backend: Robust Node.js + PostgreSQL with secure authentication/authorization
- Order Management & Commission Tracking System
- Stripe Payment Gateway Integration for secure online transactions
- Custom Mail Server (Namecheap) with dedicated email addresses: support@dokaney.store, seller-support@dokaney.store, admin@dokaney.store, marketing@dokaney.store
- Dynamic Storefront System: Separate themes and data for each seller
- Admin Dashboard: Manage sellers, admins, themes, withdrawals, and email campaigns
- React Native Mobile App: Create store in &lt;5 minutes with full management capabilities
- Email Marketing: Targeted campaigns by theme, city, or country
- Transactional Emails: Order confirmations, shipping updates, and customer notifications
- Marketing Automation: Automated email sequences for customer engagement and retention
