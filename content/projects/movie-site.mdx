## Overview

I built a Movie Application using Next.js with dynamic movie search, favorites management, and fully responsive UI. It integrates TheMovieDB API for real-time data and uses MongoDB to persist user favorites. Leveraging dynamic routing and server-side rendering, the app is optimized and scalable.

## Key features

- Favorites API with CRUD (add, delete, get, check)
- MongoDB integration for persistent favorites
- Context API for global state
- Responsive UI with Bootstrap
- Scoped styling with CSS Modules
- Reusable components
- Dynamic routing with Next.js
- Movie search via TheMovieDB API
- Custom 404 and Loading pages
- SEO-friendly MetaData
